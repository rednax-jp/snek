============================
SNEK GAME - QUICK START GUIDE
============================

To play the Snek game, you have two options:

OPTION 1: Direct play (No installation required)
-------------------------------------------------
1. Open the file "index.html" directly in your web browser
2. The game should load immediately

OPTION 2: Using a local server (Requires Node.js)
-------------------------------------------------
1. Double-click the "run.bat" file (Windows)
2. Open your browser and go to: http://localhost:3000

HOW TO PLAY
-----------
- Use the arrow keys or on-screen buttons to move the snake
- Eat the red food to grow and increase your score
- Avoid hitting the walls or your own tail
- Use the pause button or spacebar to pause the game
- Press 'R' or the Reset button to restart
- Press 'T' or the Test button to run game tests

INSTALL AS AN APP
----------------
If you're using Chrome, Edge, or another modern browser:
1. Open the game in your browser
2. Look for the install icon in the address bar
3. Click "Install" or "Add to Home Screen"

This lets you play the game offline!

TROUBLESHOOTING
--------------
- If the game is slow, try using Chrome or Edge browser
- If you can't run the server, make sure Node.js is installed
- If the controls don't work, click on the game area first to give it focus

For more detailed instructions, see README.md

Enjoy playing Snek!
