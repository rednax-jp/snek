# Assets Directory

This directory should contain the following image assets for the app:

1. `icon.png` - The main app icon (1024x1024 recommended)
2. `adaptive-icon.png` - For Android adaptive icons (foreground image, 108x108 minimum)
3. `splash.png` - Splash screen image (centered logo, 1242x2436 recommended)
4. `favicon.png` - For web (192x192 recommended)

Before publishing the app, replace these placeholder files with proper imagery that fits the Snake game theme.

Suggested themes:
- Green snake designs
- Minimalist pixel art style
- Game controller shapes

All images should be PNG format with transparency where appropriate.
